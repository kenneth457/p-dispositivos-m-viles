Definición  del Proyecto
La app consta de una tarjeta interactiva ( MainCard) que cambia su contenido ("Cargando..." / "Contenido Listo!") según el estado lógico administrado en la pantalla principal ( App.tsx) a través del gancho useState. Al presionar el botón dinámico ("Mostrar" / "Cargar"), se invierte el valor booleano del estado y se actualiza la interfaz en tiempo real.

Requisitos de la app
Node.js instalado en el sistema. Gestor de paquetes pnpm(o npm/ yarn). Aplicación Expo Go instalada en un dispositivo móvil Android o iOS.
